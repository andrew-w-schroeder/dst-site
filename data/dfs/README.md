# DraftKings DFS data

- `dk_salaries_<season>_wk<ww>.csv`: the main slate's salaries, written by 96 at every refresh until the slate locks.
- `DKSalaries_<season>_wk<ww>.csv`: optional. A salary file exported from the DK lobby (Export to CSV) and uploaded here with this exact name takes priority over the automatic pull.
- `dfs_proj_<season>_wk<ww>.csv`: the page's table at the latest refresh (projections, salaries, odds, projected ownership).
